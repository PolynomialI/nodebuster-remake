## Rules

- **Cost.** `costs[level]` is the price of the next level; max level = number of costs. No formula: every node has an explicit table (`res://Scripts/Upgrades/Upgrade.gd:24-33`).
- **Buying.** Click a visible node when you can afford it. The effect is applied once per level (`res://Scripts/Shop/UpgradeTree.gd:90-107`).
- **Visibility = unlock.** A node is shown (and only then clickable) when its rule over *scene neighbours* holds. `>=1` = neighbour has at least one level, `max` = neighbour is maxed, `or` = any. The root `Damage1` has no rule (`res://Scripts/Upgrades/UpgradeProcessor.gd:197-399`). Lines are drawn only between two visible nodes.
- **Outline colour.** yellow = maxed, green = affordable, red = not affordable (alternate palette: violet / green / dark red). Nodes with level 0 are drawn at 50% towards the background colour (`res://Scripts/UI/UpgradeIcon.gd:13-22`, `res://Scripts/Shop/UpgradeTree.gd:68-71`).
- **Camera.** Pan with right-drag or WASD/arrow keys at 260 px/s; zoom with the wheel between scales 1, 0.75, 0.5 (0.2 s quad ease-out); panning is clamped so the visible nodes stay within 100 px of the screen (`res://Scripts/Shop/UpgradesPage.gd`, `res://Scripts/Shop/UpgradeTree.gd:110-130`).
- **Position.** `x,y` = top-left in tree pixels (nodes are 16x16; `Laboratory` is 32x32). `grid` = centre relative to `Damage1` in 32 px steps, x right, y down (up is negative).

## Notes on individual nodes

Where the in-game text and the code disagree, or the code does something non-obvious. The remake should follow the code.

- **`BossDamage1`** (giant slayer): Boss multiplier is applied to the shared damage variable inside the per-enemy loop, so once a boss is hit, later enemies in the same pulse also take the boosted damage (res://Scripts/Player/PlayerCursor.gd:53-54, res://Scripts/Autoloads/Globals.gd:51-52).
- **`ExplodersChance`** (spawn exploders): Exploder weight is taken from the Square weight each session (res://Scripts/Battle/BattleScene.gd:356-358).
- **`PickupRadius1`** (magnet): +8 px pickup radius per level (base 16 px), i.e. +50% of base, additive.
- **`SpawnRate2`** (swarming): Description says +200% spawn rate; code adds 2.5 to spawn_rate_mod (+250%).
- **`PulseBolts`** (pulse bolts): Grants 3 pulse bolts per attack (pulse_bolt_count += 3).
- **`Health4`** (transplant): Level-6 cost is 0.012 while every other level is 0.01 (as shipped).
- **`YellowSpawn1`** (processor acquisition): yellow_enemy_chance += 0.001 (0.1% per spawn).
- **`MovingPulser1`** (auto pulser): Each level adds one drone (auto_pulser_count += 1).
- **`Size3`** (b.i.g.): Description says +100% attack size; code adds 1.0 to player_size (base 34 px), not to player_size_mod. Each level widens the reticle by 1 px x (1 + player_size_mod). Likely a bug in the original; reproduce as coded.
- **`Lifesteal3`** (extraction): Heals 1% of max health per enemy hit (max_health_on_hit).
- **`StealMaxHealth2`** (parasite evolution): Adds +2 (total with unending parasite = 3), matching the description's "to +3".
- **`StealMaxHealth3`** (insatiable): Adds +5 (total = 8), matching the description's "to +8".
- **`Infinity1`** (to infinity): Description "???". Code: spawn_rate_mod += 10.0 and perma_max_health_on_kill += 12.
- **`Infinity2`** (going nowhere): Description "???". No effect in code (no case in gain_upgrade); acts only as a path to the next node.
